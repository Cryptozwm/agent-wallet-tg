## 基本问题

**这个机器人收费吗？**
不收。代码全部公开，没有任何抽成。链上的 gas 费、以及币安那边可能收的费用照常由币安收取。

**机器人会拿到我的私钥吗？**
不会。私钥一直在币安 AI 钱包那边，机器人只是调用币安官方的 `baw` 命令行工具，签名在币安完成。代码里没有任何读取或保存私钥的地方。

**别人知道我的机器人用户名，能用它吗？**
不能。机器人只回应 env 里 `TG_OWNER_ID` 那个账号的私聊，其他人发什么都不理；群组里也不会回应。

**bot token 外泄了怎么办？**
拿到 token 的人能冒充机器人，但下不了单（只认 `TG_OWNER_ID`）。还是要马上到 @BotFather 发 `/revoke` 换一个新 token，填回 env 后重启。

**支持哪些链？**
只支持 BSC（BNB Chain）。

**一定要一直开着电脑吗？**
机器人跑在你自己的电脑上，电脑关机或睡眠时它就停了。
- **挂单**由币安托管，机器人停了也照样有效。
- **止盈止损、新盘狙击、自动转出**要机器人在跑才会执行。需要 24 小时运行的话，可以放在一台不关机的电脑或 Linux 服务器上。

## 安装与启动

**Windows 能用吗？**
能，要先装 WSL2（教程第 2 节），所有命令在 Ubuntu 窗口里执行。代码请 clone 在 Ubuntu 里（例如 `~/agent-wallet-tg`），不要放在 Windows 的 C 盘再从 WSL 去读。

**macOS 能用吗？**
能。用 Homebrew 装 Node.js 和 git（`brew install node git`），其他步骤一样。macOS 没有开机自启脚本，可以用 `tmux` 或 `screen` 让它在后台跑。

**`./run.sh` 显示 `Permission denied`？**
执行一次 `chmod +x run.sh`，或改用 `bash run.sh`。

**`./run.sh` 显示 `TG_BOT_TOKEN is missing`？**
env 文件没放对位置或没填 token。确认文件在 `~/.config/agent-wallet-tg/env`（不是项目文件夹里），而且有一行 `TG_BOT_TOKEN=123456:ABC...`，等号前后不要有空格。

**显示 `warning: baw not found`？**
币安 AI 钱包命令行没装好。执行 `sudo npm install -g @binance/agentic-wallet`，再用 `baw --version` 检查。
如果装在别的位置，可以在 env 里设 `BAW_BIN=/完整路径/baw`。

**`cast: command not found`？**
装完 Foundry 要开一个新的终端窗口（或执行 `source ~/.bashrc`），再执行 `foundryup`。机器人会自动去 `~/.foundry/bin/cast` 找。

**Python 版本不够？**
要 3.10 以上。Ubuntu 22.04、24.04 自带的都可以。用 `python3 --version` 检查。不需要 `pip install` 任何东西。

**机器人完全没反应？**
依序检查：
1. `run.sh` 还在跑吗？（终端窗口关了，机器人就停了）
2. 看日志：`tail -50 ~/.config/agent-wallet-tg/bot.log` 和 `tail -50 ~/.config/agent-wallet-tg/stdout.log`
3. 日志有 `401 Unauthorized`：token 填错了。
4. 发消息后机器人回「你的 Telegram ID 是…」：表示 `TG_OWNER_ID` 还没填，或填完没重启。
5. 是不是在群组里发？机器人只回应私聊。

**我发的第一条消息机器人没回？**
机器人启动时会跳过它离线期间收到的旧消息（避免执行过时的指令），启动后再发一次就好。超过 2 分钟的旧消息也一律不执行。

**怎么重启机器人？**
在跑 `run.sh` 的窗口按 `Ctrl+C`，再执行一次 `./run.sh`。
或在另一个窗口执行 `pkill -f "python3 -u bot.py"`，`run.sh` 会在 10 秒后自动重开。

**显示 `bot is already running`？**
已经有一个在跑了（例如开机自启的那个）。同一时间只会跑一个，不用再开。

**Windows 开机自启：执行 `install-task.ps1` 出现「拒绝访问」？**
用「以管理员身份运行」打开 PowerShell，执行（把 `你的用户名` 换成 Ubuntu 的用户名）：
```powershell
cd \\wsl.localhost\Ubuntu\home\你的用户名\agent-wallet-tg
powershell -ExecutionPolicy Bypass -File .\install-task.ps1
```
要取消自启：`Unregister-ScheduledTask -TaskName agent-wallet-tg -Confirm:$false`

## 钱包与登录

**一定要币安账号吗？**
要。机器人用的是币安 Web3 钱包里的 **AI 钱包（Agentic Wallet）**，要先在币安 App 里开通。

**怎么加第二、第三个钱包？**
每个钱包对应**一个币安账号**。用另一个币安账号，在机器人里再按一次 **📊 钱包状态 → ➕ 添加钱包**，就会变成钱包 B、C…。同一个账号加两次，机器人会提醒你已经加过了。

**登录链接打开后要做什么？**
用币安 App 扫码或确认，并**核对 App 上的配对码跟机器人给的一样**，不一样就不要确认。要在 5 分钟内完成。

**显示「登录过期」？**
币安的登录有有效期。按 **🔑 重新登录**，在币安 App 确认一次就好。钱包状态里会显示什么时候会被注销。

**重新登录时用错了账号？**
机器人会警告地址变了，不会把它当成原来的钱包，这个钱包也会先暂停下单。用原来的账号重新登录一次就恢复。

**怎么移除一个钱包？**
**📊 钱包状态** → 选那个钱包 → **移除**。只是机器人不再用它，币安账号和里面的钱不受影响，之后可以再加回来。

**钱怎么充进去？**
把 BNB（**BSC 链**）转到机器人显示的钱包地址。买币和手续费都用 BNB。千万不要用其他链转过来。

**「今日额度」是什么？**
币安 AI 钱包本身有每日可用额度，在币安 App 的 AI 钱包设置里调。用完了当天就送不出交易，钱包状态会显示还剩多少。

## 买卖

**为什么买入被拒绝？**
- **安全检查风险太高**（等级到 `BLOCK_RISK_LEVEL`，默认 4）：直接拒绝。
- **池子太小**（低于 `MIN_LIQUIDITY_USD`，默认 2 万美元）：会出现 **🔓 这颗仍要买（30 分钟）**，按了之后 30 分钟内可以买。
- **超过单一钱包上限**（`MAX_BNB_PER_WALLET`，默认 0.1 BNB）：只能在电脑上改 env，Telegram 里改不了，这是刻意的安全设计。
- **BNB 不够**：每个钱包会先留 0.002 BNB 当手续费。

**预览失效了？**
预览 90 秒后失效（`CONFIRM_TTL_SECONDS`），避免你按到价格已经变了的旧预览。重新按一次买入金额就好。

**「链上试跑失败」是什么？**
送出前在链上模拟了一次，结果会失败，所以什么都没送出。括号里会附上合约给的原因，例如还没开始、额度已满、余额不够。

**「结果未知」？**
送出后没收到明确结果。机器人**不会自动重试**，避免买两次或卖两次。等一下按 **📜 最近成交** 或去 BscScan 查。

**`0.0(4)52` 是什么意思？**
小数点后有 4 个 0，也就是 `0.000052`。价格很小的币用这种写法比较好读。

**卡片读不到数据、很慢？**
默认用 BSC 公共节点，偶尔会慢或限流。可以在 env 里设 `RPC_URL=` 换成你自己的节点，重启后生效。

**滑点怎么设？**
默认 `auto`，由币安决定。也可以在 **⚙️ 设置 → 🎚 滑点** 改。税很高的币可能要把滑点调高才买得到。

**持仓里怎么看不到我 mint 的 NFT？**
卡片和总览只显示代币（ERC20）。NFT 在 BscScan 上用你的钱包地址查得到。

## 内盘、Agent ID、项目合约

**什么是内盘？**
还没毕业、还在发射台曲线上的币（Four.meme、Flap、gang.fun、Agent Curve）。币安的一般兑换买不到，机器人会自动认出来，直接跟曲线合约买卖。毕业后自动改走 PancakeSwap。

**内盘买不了，说要开发者模式？**
内盘买卖和项目合约走的是「合约调用」，要先在币安 App 的 AI 钱包设置里打开**开发者模式**。外盘交易不需要。
开发者模式有到期时间，**📊 钱包状态 → 详细** 会显示到什么时候，过期了在 App 里再打开一次。

**什么是 Agent ID？哪里需要？**
Agent ID 是币安 AI 钱包可以领取的 `.ai` 身份（链上 NFT）。有些盘只让持有 Agent ID 的钱包买，例如 Four.meme 的 Agent 专属盘、Flap 的 Agent ID 门槛盘、Agent Curve。
- 钱包状态会显示每个钱包的 Agent ID，没有的会标「没有 Agent ID」。
- 在终端执行 `baw wallet agent-id` 也能查。
- 领取入口在币安 App 的 AI 钱包里（以币安 App 为准）。**每个钱包都要有自己的 Agent ID**，只有钱包 A 有的话，钱包 B 照样买不了。

**能 mint NFT 吗？**
能（限 BSC）。把项目合约地址贴给机器人，按 **铸造** 那个按钮，照提示填数量，先模拟再确认。
- 白名单盘通常要一串「证明」（proof）或后台签名，要你自己从项目网站拿到再填。
- 也可以把别人成功 mint 的交易 hash 贴过来「照抄」。

**项目给了一段「给 AI agent 的说明」怎么用？**
整段贴给机器人，它会读出合约和函数，生成预售／铸造卡片。读不懂的话，会告诉你缺什么。

**「照抄」别人的交易安全吗？**
机器人会把交易里出现的对方地址换成你自己的地址，再先模拟一次给你看。还是要看清楚预览：花多少、拿到什么、钱给谁。单纯转账或部署合约的交易不能照抄。

## 自动功能

**止盈止损多久检查一次？**
每 20 秒检查一次链上报价，碰到条件就自动卖出，不会再问你（设置时已经确认过）。机器人要在跑才会检查。

**新盘狙击会不会乱买？**
默认是**模拟**，只回报「如果是真的会买哪颗」。要按 **⚡ 改成真的下单** 并确认后才会真的买。可以设每个钱包买多少、每天最多花多少、每天最多几颗。建议先看几天模拟结果。

**自动转出要怎么设？**
主钱包地址**只能在电脑上**填：`~/.config/agent-wallet-tg/wallets.json` 的 `payout`（格式参考 `wallets.example.json`）。而且要先把这个地址加进币安 App 的地址簿，否则币安会拒绝。

**想关掉所有自动功能？**
**🎯 止盈止损 → 🗑 全部清除**；**⚡ 新盘狙击** 里关闭；**⚙️ 设置 → 📤 自动转出** 关闭。或直接停掉机器人。

## 日常维护

**怎么更新到新版本？**
```bash
cd ~/agent-wallet-tg
git pull
pkill -f "python3 -u bot.py"   # run.sh 会在 10 秒后用新版重开
```
你的设置、钱包、规则都在 `~/.config/agent-wallet-tg/`，更新不会动到。

**换语言、换时区？**
env 里改 `BOT_LANG=zh`（简体中文）或 `en`（英文）；`TZ_OFFSET_HOURS=8` 改成你的时区（例如 `0` 是 UTC）。改完重启。

**换电脑？**
在新电脑照教程装好，再把旧电脑的 `~/.config/agent-wallet-tg/` 整个复制过去，钱包要在新电脑上重新登录一次。

**完全移除？**
1. 停掉机器人（Windows 自启的话先执行上面的 `Unregister-ScheduledTask`）。
2. 删掉项目文件夹和 `~/.config/agent-wallet-tg/`。
3. 到 @BotFather 发 `/deletebot`。

币安 AI 钱包本身不受影响，钱都还在币安那边。
